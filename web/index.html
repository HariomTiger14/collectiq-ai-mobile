Valuation Philosophy

Recognition is assisted. Valuation is evidenced.

PackLox shows a value only when a connected catalog or marketplace provider returns usable evidence. If trusted evidence is not available, the app explains why instead of guessing.

Deterministic provider routing

Trading cards, games, and supported catalog categories can route to PriceCharting. Broader marketplace categories can route to eBay signals when approved data is available.

Sold comps over asking prices

PackLox distinguishes completed-sales evidence from active listing asking prices. Lower-trust signals are labeled clearly.

Confidence and attribution

Every valuation response is designed to include provider, currency, timestamp, range, confidence, and match reason.

Collector Workflow

Scan, review, correct, and save.

  1. Identify Capture the item and review extracted identity details before pricing.
  2. Validate Match against connected catalog or marketplace evidence with confidence rules.
  3. Track Save the item and valuation snapshot to the collector portfolio.

Data Handling

Built for responsible provider use.

Responsible caching

PackLox caches valuation lookups to reduce repeated provider calls for identical or similar items.

No bulk redistribution

Provider data supports user-facing valuation context, not raw marketplace data downloads.

User-owned portfolios

Saved records belong to the user account and can include photos, notes, and dated value snapshots.

Clear unavailable states

When there is not enough trusted evidence, PackLox explains why the value is unavailable.
