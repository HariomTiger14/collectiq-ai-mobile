What PackLox Does

A mobile collection system built around evidence.

AI Identification

Users capture collectible images and PackLox extracts likely title, category, edition, set, SKU, card number, and condition clues.

Portfolio Ledger

Collectors save items to their account with photos, metadata, valuation snapshots, notes, and change history.

Pricing Providers

PackLox routes items to trusted pricing sources by category and clearly labels provider, currency, timestamp, and confidence.

Valuation Philosophy

No AI-invented prices.

PackLox uses AI for recognition, not valuation. A price is shown only when a connected catalog or marketplace data provider returns usable evidence. If trusted evidence is not available, PackLox shows a clear unavailable state instead of guessing.

Deterministic provider routing

Trading cards, games, and supported catalog categories can route to PriceCharting. General marketplace categories can use eBay signals where approved data is available.

Sold comps over asking prices

PackLox distinguishes completed sales evidence from active listing asking prices. Asking prices are lower-trust signals and are labeled as such.

Confidence and attribution

Every valuation response is designed to include source attribution, currency, timestamp, range, confidence, and the reason a match was accepted or withheld.

Collector Workflow

Scan, review, correct, and save.

  1. 1. Identify Capture an item and review extracted identity details before pricing.
  2. 2. Validate Match against connected catalog or marketplace evidence with clear confidence rules.
  3. 3. Track Save the item and valuation snapshot to the collector portfolio for future review.

Data Handling

Built for responsible provider use.

Responsible caching

PackLox caches valuation lookups to reduce repeated provider calls for identical or similar items.

No bulk redistribution

Provider data is used to support user-facing valuation context, not to expose raw marketplace data for download.

User-owned portfolios

Saved portfolio records belong to the user account and can include personal photos, notes, and dated valuation snapshots.

Clear unavailable states

When PackLox cannot find enough trusted evidence, the app explains why the value is unavailable.
